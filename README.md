# Arkaius Game

MVP web de defensa lateral 2D original construido con Phaser 3, TypeScript y Vite.

## Ejecutar

```bash
npm install
npm run dev
```

## Controles

- Botones inferiores: invocar unidades y lanzar Arcane Blast.
- Teclas rápidas: `1` Soldier, `2` Archer, `3` Tank, `4` Mage, `Q` Arcane Blast.

## Estado del MVP

Incluye menú, escena de juego, escena de mejoras, economía de energía, IA enemiga, unidades automáticas, héroe básico, proyectiles, combate, victoria/derrota y guardado de monedas en `localStorage`.
